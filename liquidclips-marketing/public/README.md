## Add new assets here · DO NOT lose

When adding a new image / video / pose:

1. Drop the file in the right subfolder above (or create a new one with a short name).
2. Update this README so the consuming component is named next to the file.
3. If the new file replaces an old one, mark the old one `(DEPRECATED)` here and keep it on disk for one release as a fallback.

This document is the contract between Daniel's brand kit (in
`/private/tmp/lc-dashboard/brand/`) and the live marketing surface.
