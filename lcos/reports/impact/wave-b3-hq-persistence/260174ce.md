### 10. Data model

**Added:**
```
Table lcos_event
  id BIGINT PK (auto)
  topic VARCHAR(120) NOT NULL
  payload_json TEXT NOT NULL DEFAULT '{}'
  ts_ms BIGINT NOT NULL          -- client-generated wall-clock
  source_sha VARCHAR(40)          -- optional bundle SHA
  session_id VARCHAR(80)          -- optional lcDiag session id
  payload_hash VARCHAR(80)        -- sha256(sorted canonical JSON), 64-char
  created_at TIMESTAMPTZ NOT NULL DEFAULT now()
  CONSTRAINT uq_lcos_event_dedupe UNIQUE (topic, ts_ms, payload_hash)

Indexes
  ix_lcos_event_topic_ts   ON (topic, ts_ms DESC)
  ix_lcos_event_session    ON (session_id, ts_ms DESC)
```
