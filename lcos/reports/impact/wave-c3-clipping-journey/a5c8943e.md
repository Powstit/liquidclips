### 12. Live customer walkthrough steps (for FIXED_UNPROVEN → CLOSED prep)

Steps a human tester runs on the promoted RC1 bundle:

1. Install RC1 bundle · open Liquid Clips · sign in with a JWT-holding test
   account. → CreateClips route renders. → `create_screen_mounted` observed
   in Railway backend logs within ~2s.

2. Drop a real 10–60 second .mp4 onto the app shell. → `video_input_selected`
   → `sidecar_probe_before_ingest` → `ingest_started` fire in order.
   Preflight passes silently. → `source:drop` emits into
   `bus.emit(...)`. → Sidecar receives `sidecar.startRun` with a real
   `run_id`.

3. Wait for the pipeline to complete. → StageRail walks `ingest → audio →
   transcribe → llm → cut → reframe → thumbs`. → `clips_written` fires with
   `clip_count >= 1`. → `fresh_clipping_engine_proven` fires only if the
   first clip's `cut_path` / `vertical_path` resolves via `fs.exists`. →
   Sidecar posts `POST /telemetry/clip_run` with `status="success"` +
   `clips_generated >= 1`.

4. Navigate to Workstation. → ClipCard grid renders one card per clip. →
   Click "Reveal in Finder" · Finder opens to the file · `local_clip_reveal_clicked`
   + `local_clip_access_proven { via: "reveal_in_finder" }` fire. → Click
   "Copy path" · "Path copied" toast · clipboard contains the absolute
   path. → Click "Open clip" · CockpitDock focuses the clip · StageRail
   inspector renders.

5. Open a real campaign from the Campaigns tab. → `activeCampaignId`
   populates in the mode-store. → Click "Submit to Whop" on a ClipCard. →
   SubmitToWhopModal opens with the real campaign name + Whop reward URL.
   → Paste a real post URL · pick permission_type · click Submit. →
   `POST /submissions` fires with `campaign_id: <real-slug>` · 201 · UI
   flips to Submitted. → `submission_created { campaign_id: <real-slug> }`
   observed in Railway logs.

6. Verify via `curl` on the backend admin surface:
   ```
   curl -H "authorization: Bearer <admin-jwt>" \
     https://api.liquidclips.app/admin/clip-runs?hours=1
   ```
   → Response includes the `run_id` from step 3 with `status="success"` +
   `clips_generated >= 1` + a 7-stage timeline.
