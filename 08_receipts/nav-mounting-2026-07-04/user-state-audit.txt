  the function itself. Behaviour of the auth storage layer is
  identical.

  component instances embedded inside each port surface. Phase 8
  mounted these surfaces without touching the DemoOverlay contract,
  so every key remains reachable at the same route it did after

  `liquidclips-marketing/src/middleware.ts` which Phase 8 did not

  Phase 8's App.tsx edit (Mount #1) touched only the AuthGate function
  body — the boot-effect consumers of both QA hooks are untouched.
