     Fixes the "half-published" failure mode where installed clients
     could self-update to a draft asset.

BLOCKED ON DANIEL (decisions required before further hardening)
────────────────────────────────────────────────────────────────────────

1. Sentry DSN (P1 — crash telemetry)
   The Rust panic hook writes crashes to ~/LiquidClips/.last-crash.json,
   but nothing forwards them upstream. To close the loop we need a
   crash-reporting DSN.
   Options:
     (a) sentry.io free tier — Daniel signs up, provides DSN. Fastest.
     (b) Self-host GlitchTip on Railway — free, we own the data.
     (c) Defer — accept blind crashes for another release window.
   Not opening an account on Daniel's behalf.

2. Canary channel friends list (P2 — pre-flight)
   Before the flip-to-Latest step promotes a draft, we want 3–5 people
   on macOS Silicon + Intel to install from the draft assets and confirm
   no boot regression.
   Need from Daniel: 3–5 email or phone identifiers of people who agree
   to run canary builds. Cannot guess names.
   Not shipping without this in v2.2.35 — the draft-first CI already
   gives us the reversibility we need for now; the canary list turns
   that reversibility into proactive detection.

3. GitHub Environment `production` (P1 — gated flip)
   The flip-to-latest job supports either:
     (a) `environment: production` with required reviewers. GitHub
         blocks the job until a reviewer approves. Requires the repo to
         be on a tier that allows required-reviewer environments
         (private repos need Pro+ or Team+).
     (b) workflow_dispatch gate (current default). Any maintainer who
         can trigger workflows can flip. Not as strong as (a), but no
         tier upgrade needed.
     (c) No gate — auto-flip on build success. Reverses today's win.
         Not recommended.
   Currently shipped: (b), with (a) commented out and ready to activate
   by uncommenting one line. Daniel decides which path.
